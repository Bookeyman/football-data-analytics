# Python notebooks

В этой папке находятся ноутбуки для подготовки данных и аналитики.

- **json_to_excel.ipynb** — чтение JSON, преобразование полей и экспорт структурированных данных в Excel с помощью pandas.
- **match_report.ipynb** — SQL-выборки из SQLite для сравнения двух команд, включая турнирную позицию и последние матчи.
- **radar.ipynb** — расчёт статистики игроков на 90 минут и подготовка радарного сравнения игроков одной позиции.

Ноутбуки рассчитаны на Jupyter/Google Colab. Перед запуском проверьте пути к исходным JSON и базе данных, а также наличие необходимых библиотек. Некоторые пути в текущих версиях привязаны к Google Drive.
