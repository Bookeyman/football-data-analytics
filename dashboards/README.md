# Dashboards

В этой папке находятся изображения аналитических отчётов, созданных в Metabase.

- **team_review.png** — обзор одной команды: командные показатели, результативность, xG и вклад игроков.
- **teams_comparison.png** — сравнение двух клубов по турнирным результатам, очным матчам и игровым метрикам.
- **two‑player radar.png** — сравнение профилей двух игроков одной позиции по нормализованным показателям.

Скриншоты показывают назначение отчётов и примеры аналитических вопросов, которые они помогают исследовать.
