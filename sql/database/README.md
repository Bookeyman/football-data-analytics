# Database scripts

SQL-скрипты для создания структуры и вспомогательной логики SQLite.

- **01_schema.sql** — таблицы и связи между сущностями.
- **02_indexes.sql** — индексы для ускорения типовых запросов и соединений.
- **03_views.sql** — представления для повторного использования сложных выборок и аналитических показателей.
- **04_triggers.sql** — аудит изменений данных и проверки отдельных бизнес-правил.

Скрипты содержат DDL, но не саму базу и не исходные данные. Для полноценного запуска необходимо учитывать порядок выполнения и наличие требуемых таблиц/данных.
