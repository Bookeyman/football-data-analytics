# SQL analytics case studies

Каждый файл демонстрирует решение отдельной аналитической задачи:

1. **01_team_performance.sql** — турнирная таблица и эффективность команд в атаке.
2. **02_player_performance.sql** — рейтинг игроков с учётом игрового времени и вклад в голы.
3. **03_player_value_epv.sql** — вклад игроков в EPV через продвижение мяча, открытые игровые эпизоды и стандарты.
4. **04_game_state_analysis.sql** — набор очков после отставания и после выхода вперёд.
5. **05_goal_contribution.sql** — связки бомбардиров и ассистентов, запасные, победные голы и распределение по позициям.
6. **06_transfer_analysis.sql** — анализ входящих трансферов и сумм по клубам.

В начале каждого файла описаны вопрос, источники данных и логика интерпретации результата. Запросы требуют локальной SQLite базы с соответствующими таблицами и VIEW.
