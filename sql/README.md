# SQL

SQL-раздел содержит два направления:

- **database/** — DDL и логика базы SQLite: таблицы, индексы, представления и триггеры.
- **analytics/** — самостоятельные аналитические кейсы, показывающие применение SQL для ответов на вопросы о командах, игроках, игровых ситуациях, голах и трансферах.

Сначала изучите и выполните скрипты из `database/` на чистой SQLite базе, затем используйте аналитические запросы после загрузки соответствующих данных.
